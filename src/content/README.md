# Content

Structured site copy lives here as Markdown. Edit these files instead of hardcoding pages.

| Collection | Folder | Used on |
| --- | --- | --- |
| Projects | `projects/` | Home, `/projects`, `/projects/[slug]` |
| Experience | `experience/` | `/cv` |
| Education | `education/` | `/cv` |

Identity, skills, and UI chrome live in `src/lib/`. The merged CV source (for you to complete) is `cv-source.md`.

Frontmatter is bilingual: `{ en, es }`. English is the default language of the site.
